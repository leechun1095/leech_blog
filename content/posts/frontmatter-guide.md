Frontmatter는 Markdown 파일의 맨 앞에 위치한 메타데이터 블록입니다. 잘 설계해 두면 목록, 검색, 태그 필터, 연관 글 추천까지 모두 이 정보만으로 처리할 수 있습니다.

## 필수 필드

이 블로그는 다음 다섯 가지 필드를 사용합니다.

1. `title` — 글의 제목
2. `date` — `YYYY-MM-DD` 형식의 작성일
3. `description` — 목록과 검색 결과에 노출되는 요약
4. `tags` — 문자열 배열
5. `slug` — URL 경로 (선택)

### slug는 선택 사항

`slug`를 생략하면 파일명이 그대로 slug가 됩니다. 이 글도 frontmatter에 slug가 없기 때문에 파일명인 `frontmatter-guide`가 주소로 쓰입니다.

## 날짜는 따옴표로 감싸기

YAML 파서는 따옴표 없는 날짜를 `Date` 객체로 해석합니다. 시간대 문제를 피하려면 문자열로 적는 편이 안전합니다.

```yaml
date: "2026-10-14"   # 권장
date: 2026-10-14     # Date 객체로 변환됨
```

## 태그 운영 팁

- 태그는 **적게, 일관되게** 사용합니다
- 대소문자와 띄어쓰기를 통일합니다
- 글 하나에 2~4개 정도가 적당합니다

태그가 잘 정리되어 있으면 연관 포스팅 추천의 품질도 함께 올라갑니다.

## 체크리스트

- [x] 모든 글에 `title`과 `date`가 있는가
- [x] `description`이 한두 문장으로 요약되어 있는가
- [ ] 새로 만든 태그가 기존 태그와 중복되지 않는가
